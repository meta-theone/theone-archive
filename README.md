# 더원사업단 자료실 (theone-archive)

CA(위촉설계사) 배포용 교육 · 영업 · 상품 자료를 발행하는 GitHub Pages 자료실입니다.

## 🌐 자료실 주소

배포 후 아래 주소에서 확인할 수 있습니다.

```
https://meta-theone.github.io/theone-archive/
```

## 📁 폴더 구조

```
theone-archive/
├── index.html              # 자료실 홈
├── .nojekyll               # GitHub Pages가 파일을 그대로 서빙하도록 설정
├── assets/                 # 공통 이미지·CSS 등
└── materials/              # 자료 본문
    ├── education/          # 교육 자료
    ├── sales/              # 영업 자료
    ├── products/           # 상품 자료
    └── incentives/         # 시책·시상
```

## ✍️ 자료 올리는 방법

1. `materials/<카테고리>/` 폴더에 자료 페이지(HTML)와 PDF를 추가
2. 변경사항을 커밋 후 push
   ```
   git add .
   git commit -m "자료 추가: <제목>"
   git push
   ```
3. 1~2분 후 자료실 주소에 자동 반영

## 🔒 공개 범위

- 현재 **Public 저장소 + GitHub Pages(무료)**
- 웹사이트는 URL을 아는 사람이면 접속 가능
- 필요 시 GitHub Pro로 전환하여 저장소 소스를 비공개로 전환 가능
