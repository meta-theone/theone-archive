# 정산센터 카드 활성화 안내

## 🎯 작업 목표

withtheone.com/tools/ 의 **「정산 센터」 카드**(현재 "준비중")를 활성화하여
v2.3 수수료 자동분배 시스템에 연결.

---

## 📂 배포할 파일

`settlement-center/` 폴더 통째로 withtheone.com 저장소에 추가하세요.

| 파일 | 용도 |
|---|---|
| `index.html` | 메인 (v2.3-beta) — `/settlement-center/` 진입 시 자동 로드 |
| `v2.3-beta.html` | 명시 버전 백업 |
| `v2.3-alpha.html` | 직전 버전 (참고용) |
| `robots.txt` | 검색엔진 노출 차단 |

배포 후 URL: **`https://withtheone.com/settlement-center/`**

## 🔧 정산센터 카드 HTML 수정

### Before (현재 "준비중")
```html
<div class="card-tool">
  <div class="card-icon">📋</div>
  <span class="card-badge">준비중</span>
  <h3>정산 센터</h3>
  <p>메타리치 전체 수수료 정산을 관리합니다.</p>
  <button class="btn-go disabled">바로가기</button>
</div>
```

### After (활성화)
```html
<div class="card-tool">
  <div class="card-icon">📋</div>
  <span class="card-badge live">LIVE</span>
  <h3>정산 센터</h3>
  <p>메타리치 전체 수수료 정산을 관리합니다.<br>
     <small>MYGA 표준 · 7단계 조직 · T/H/M/S 분배 · 본부×보험사 피벗</small></p>
  <a href="/settlement-center/" class="btn-go">바로가기</a>
</div>
```

핵심 변경 3가지:
1. `<span class="card-badge">준비중</span>` → `<span class="card-badge live">LIVE</span>`
2. 설명에 기능 요약 추가 (선택)
3. `<button class="btn-go disabled">바로가기</button>` → `<a href="/settlement-center/" class="btn-go">바로가기</a>`

## 🚀 배포 절차 (PowerShell)

withtheone.com 저장소가 로컬에 있다고 가정 (예: `C:\dev\withtheone-site`).

```powershell
# 1. 배포 폴더를 withtheone.com 저장소로 복사
Copy-Item -Path "C:\Users\강광원\OneDrive\바탕 화면\settlement-center" `
          -Destination "C:\dev\withtheone-site\settlement-center" `
          -Recurse -Force

# 2. tools/index.html 또는 해당 페이지 열어서 정산센터 카드 HTML 수정
#    (위의 Before → After 참고)

# 3. 커밋 & push
cd "C:\dev\withtheone-site"
git add settlement-center/ tools/index.html  # (실제 경로에 맞게)
git commit -m "Add: 정산 센터 v2.3-beta 배포 (메타리치 자동분배)"
git push

# 4. GitHub Pages / Netlify / Vercel 자동 배포 대기 (1~3분)

# 5. 확인
# https://withtheone.com/settlement-center/
```

## 🔄 향후 업데이트 방법

v2.3.1 / v2.4 등 새 버전이 나오면:

```powershell
# 1. 새 HTML을 settlement-center/index.html에 덮어쓰기
Copy-Item "신버전.html" "C:\dev\withtheone-site\settlement-center\index.html" -Force

# 2. 명시 백업도 함께
Copy-Item "신버전.html" "C:\dev\withtheone-site\settlement-center\v2.3.1.html" -Force

# 3. push
cd "C:\dev\withtheone-site"
git add settlement-center/
git commit -m "Update: 정산센터 v2.3.1"
git push
```

⚠️ **IndexedDB는 도메인+경로 단위로 격리되므로**, 같은 `/settlement-center/` 경로면
기존 사용자 데이터는 유지됩니다.
