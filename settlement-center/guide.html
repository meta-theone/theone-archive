01정산 센터란?

정산 센터는 메타리치 본사 산하 모든 사업단·본부·지점·팀·CA의 수수료를 통합 관리하는 웹 도구입니다.

🎯 무엇이 가능한가요?

  • 보험사가 보내는 원장 엑셀(17컬럼)을 그대로 업로드 → 자동 인식
  • 4,500명 이상 CA에게 T(총)·H(본부)·M(모집)·S(시책) 4분류로 자동 분배
  • 본부×보험사 피벗표 (MYGA payment_LP.php 양식 호환)
  • 지급월 단위 정산 + 세전·세후(3.3% 사업소득세) 자동 계산
  • CA 명세서 → 카톡·인쇄·PDF 즉시 출력
  • 마감 잠금 → 수정 차단 (감사 추적 가능)

🔒 데이터는 어디에 저장되나요?

모든 데이터는 접속한 브라우저의 IndexedDB에 저장됩니다.
서버로 전송되지 않으므로 안전합니다. 단, 브라우저 캐시를 지우면 데이터가 사라지므로 정기 백업 필수입니다.

💡 어떤 분이 사용하시나요?

역할주요 사용 기능
본사 정산 담당자원장 업로드 → 분배 실행 → xlsx 내보내기
사업단장 / 본부장본부×보험사 피벗 · 산하 CA 명세 확인

0210분 빠른 시작 — 처음 사용자용

아래 10단계를 순서대로 따라하시면 정산 결과까지 확인하실 수 있습니다.

1
홈 화면 진입
정산 센터에 처음 접속하면 🏠 홈 탭이 열립니다. 우상단에 「DB 준비중」 → 「DB 정상」으로 바뀌면 시작 가능.
2
조직도 데모 자동 생성 → 🏢 조직도(7단계) 탭 클릭 → 🌱 메타리치 데모 버튼 클릭
메타리치 본사 → 상위본부 2 → 본부 4 → 사업단 13 → 지점 약 65 → 팀 약 195개가 자동 생성됩니다.
3
보험사 14개 표준 코드 시드 → 🏛️ 보험사(코드) 탭 → 🌱 14개 표준 시드 클릭
dy(메리츠)·lg(KB)·ss(삼성)·db(DB)·hd(현대)·sd(한화)·dh(롯데)·gr(MG)·sy(흥국)·ag(AIG)·nh(농협)·tk(하나)·ac(처브)·00(전체) 자동 등록
4
직급별 분배율 시드 → ⚙️ 룰 탭 → 📋 직급별 → 🌱 메타리치 표준 8단계 시드
CA1(52.5%) · CA2(58%) · SCA(63%) · MCA(68%) · 팀장(73%) · 지점(78%) · S지점(83%) · 본부(88%) 입력됨
5
직책 오버라이드 입력 → 같은 탭의 👔 직책 오버라이드 서브탭
예시값: 팀장 3 / 지점장 2 / 사업단장 1.5 / 본부장 1 / 상위본부장 0.5 / 본사 0.3 → 💾 저장
6
CA 마스터 일괄 등록 → 👥 CA 탭 → 📥 xlsx 일괄 → 테스트_CA마스터_v23.xlsx 업로드
필수 컬럼: 이름 · MT코드 · 사용인코드 · 팀명 · 직급 · 위촉일 · 상태
7
보험사 원장 업로드 → 📥 원장 탭 → 종목·보험사 선택 → 17컬럼 xlsx 다중 업로드
GA수수료 음수는 자동으로 환수 처리됩니다.
8
정산 워크플로우 확인 → 🔄 정산 워크플로우 탭
5단계 진행 상태: 마감입력 → 마감작업 → 정산작업 → 마감잠금 → 검증
9
지급월 분배 실행 → 🧮 지급월 분배 탭 → 지급월 선택 → ⚡ 분배 실행
결과: 수령인별 T·M·H·S·세전·세후 자동 계산
10
결과 확인 & xlsx 내보내기 → 분배 결과 → 📤 xlsx 클릭 → 다운로드
또는 📄 CA명세(THMS) 탭 → 개별 CA 명세서 → 카톡용 복사
✅ 여기까지 완료하면 매월 정산 한 사이클이 끝납니다. 다음 달은 6번(CA)·7번(원장)·9번(분배)만 반복하시면 됩니다.

👔 직책 오버라이드 (H = 본부수수료)

조직장은 본인 직접 모집 외에 산하 CA의 GA수수료에 대한 H% 오버라이드도 받습니다.

직책예시 H%
팀장3%
지점장2%
사업단장1.5%
본부장1%
상위본부장0.5%
본사 본사장0.3%

💰 세금·지급시기

  • 사업소득세율: 기본 3.3% (세전→세후 자동 차감)
  • 디폴트 지급시기: 말일(1) · 추가(2) · 27일(3) 디폴트
  • 디폴트 정산구분: 세전(1) · 세후(2) 디폴트
분배 산식:
T(총) = 보험사 지급 GA수수료
M(모집) = T × 직급분배율
H(본부) = T × 직책오버라이드%
S(시책) = 별도 인센티브 (수동 추가)
세후 = (M + H + S) × (1 - 0.033)

💡 마감 잠금 후에도 「🧮 지급월 분배」와 「📊 본부×보험사 피벗」 결과 조회는 가능합니다. 단, 원장 수정만 차단됩니다.

14💾 데이터 백업·복원

백업 (정기 권장)

  1. 우상단 💾 백업 버튼 클릭
  2. JSON 파일 자동 다운로드 (파일명: 메타리치_v2.3_백업_YYYY-MM-DD.json)
  3. 안전한 곳(OneDrive·외장하드)에 보관
💡 권장 백업 주기: 매주 1회 + 매월 분배 실행 후 1회. 최소 2개월치 보관.

복원

  1. 우상단 📂 복원 버튼 클릭
  2. JSON 파일 선택
  3. "현재 데이터 덮어씁니다" 확인 → 확인
  4. 복원 완료 메시지 (몇 초~몇 분 소요)
⚠️ 복원은 덮어쓰기입니다. 현재 데이터는 모두 삭제되므로 복원 전에 반드시 현재 데이터 백업하세요.

IndexedDB 위치

브라우저별 저장 위치:

  • Chrome / Edge: %LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB
  • Firefox: 프로필 폴더 내 storage\default
⚠️ 브라우저 캐시 삭제 시 데이터 소실 위험!
Chrome 설정 → "인터넷 사용 기록 삭제" 시 IndexedDB도 함께 삭제될 수 있습니다. 반드시 사전 백업하세요.

15❓ 자주 묻는 질문

Q. 원장을 잘못 올렸는데 다시 올릴 수 있나요?

A. 📥 원장 탭에서 해당 원장의 「삭제」 버튼 → 다시 업로드. 단, 마감 잠금된 원장은 삭제 불가입니다.

Q. CA 명세서를 4,500명 한번에 출력할 수 있나요?

A. 현재 v2.3-beta는 1명씩 출력입니다. 다음 버전(v2.4)에서 일괄 PDF 출력 기능을 추가할 예정입니다.
임시로 「🧮 지급월 분배」 결과 xlsx로 받아서 메일머지(Excel + Word)로 처리하시면 됩니다.

Q. 같은 PC에서 두 명이 다른 데이터로 사용할 수 있나요?

A. 브라우저 프로필을 분리하시면 가능합니다. Chrome에서 새 프로필 생성 → 그 프로필에서 접속 → 별도 IndexedDB 사용.

Q. 모바일에서도 사용 가능한가요?

A. 표시는 가능하지만 편집 작업은 PC 권장입니다. xlsx 업로드·다중 선택은 모바일에서 제한이 있습니다.

Q. 분배 결과가 MYGA와 다릅니다.

A. 다음 5가지를 점검하세요:

  1. CA의 직급이 정확한가? (메타리치 본사 직급결정 공문 기준)
  2. 직책 오버라이드% 값이 메타리치 정책과 일치하는가?
  3. 원장의 「사용인코드」가 CA 마스터의 「사용인코드」와 정확히 매칭되는가?
  4. GA수수료 음수(환수)가 올바르게 처리되었는가?
  5. 세금(3.3%) 적용 시점이 일치하는가? (세전/세후 구분)

Q. 데이터를 다른 PC로 옮기려면?

A. 💾 백업 JSON → USB·OneDrive로 이동 → 다른 PC에서 📂 복원. 완료까지 약 1~5분.

Q. v2.3-alpha와 v2.3-beta 차이는?

A. beta는 alpha 단계에서 발견된 이슈를 보완한 버전입니다. beta 사용 권장이며 alpha는 참고용으로만 유지됩니다.

16🛠 문제 해결

1. 화면이 안 뜹니다 (백지)

  • 새로고침 F5 또는 Ctrl + Shift + R (강제 새로고침)
  • 다른 브라우저로 시도 (Chrome / Edge 권장)
  • 인터넷 연결 확인 (외부 CDN 라이브러리 로드 필요)

2. xlsx 업로드 시 오류 발생

  • 파일 확장자가 .xlsx인지 확인 (xls·csv 미지원)
  • 파일 크기 100MB 초과 시 잘라서 업로드
  • 첫 행이 컬럼명인지 확인 (헤더 필수)
  • 한글 컬럼명 그대로 사용 (정산월구분·회사코드·사용인코드 등)

3. 분배 실행 시 결과가 0원으로 나옴

  • CA 마스터의 「사용인코드」와 원장의 「사용인코드」 매칭 확인
  • 직급별 분배율(M%) 시드 완료 여부 확인
  • 해당 월의 원장이 실제 존재하는지 확인 (📥 원장 탭)

4. 데이터가 갑자기 사라졌습니다

  • 브라우저 캐시·기록 삭제 여부 확인 → 백업 JSON으로 복원
  • 시크릿/InPrivate 모드는 종료 시 데이터 자동 삭제됨 → 일반 모드 사용
  • 다른 브라우저·프로필로 접속한 게 아닌지 확인

5. 「DB 오류」 빨간 뱃지 표시

  • F12 → Console 탭에서 오류 메시지 확인
  • 브라우저 IndexedDB 권한 거부됨 (보안 설정 확인)
  • 최신 Chrome/Edge 사용 권장 (Chromium 100 이상)
